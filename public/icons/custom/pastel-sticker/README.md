# Pastel sticker icons

25 SVG concepts, based on the approved smiling bottle with mint pastel colors.

ViewBox: 128 × 128. Transparent backgrounds. Rounded strokes. Used in the app through `src/components/app-icons.tsx` and `care-illustration.tsx`. These detailed illustrations suit feature tiles and headers; simplify facial details before using at small navigation sizes.

Palette: outline #14667D, mint #B8E7E5, teal #79CDCE, surface #F1FAFB, pink #EEA3AE, peach #FFDCC5.
